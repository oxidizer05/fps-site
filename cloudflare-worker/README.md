# Счётчик посетителей (Cloudflare Worker)

Считает, сколько всего людей заходило на fpsgirls.com и сколько заходят часто
(в 3+ разных дня). Работает на твоём домене через Cloudflare, бесплатно,
анонимно (никаких cookie и персональных данных — только случайный id в браузере).

Код воркера — `counter.js`. Страница сайта дергает адрес `/api/counter/hit`.

## Настройка в Cloudflare (один раз, ~5 шагов)

1. Зайди на [dash.cloudflare.com](https://dash.cloudflare.com) под своим аккаунтом
   (тот же, где домен fpsgirls.com).
2. Слева **Storage & Databases → KV** → **Create a namespace**. Имя: `fpsgirls_counter`.
   Нажми **Add**.
3. Слева **Workers & Pages → Create → Workers → Create Worker**. Имя, например,
   `fpsgirls-counter`. Нажми **Deploy** (пока с шаблоном), затем **Edit code**:
   удали весь код и вставь содержимое `counter.js` из этого репозитория →
   **Deploy**.
4. Привяжи хранилище к воркеру: открой воркер → **Settings → Bindings →
   Add → KV namespace**. Variable name: `COUNTER` (ровно так!), KV namespace:
   `fpsgirls_counter`. Сохрани и передеплой (**Deploy**).
5. Направь адрес `/api/counter*` на воркер: воркер → **Settings → Domains &
   Routes → Add → Route**. Zone: `fpsgirls.com`, Route:
   `fpsgirls.com/api/counter*`. Добавь.

Готово. Проверь в браузере: открой
`https://fpsgirls.com/api/counter` — должно показать `{"total":0,"frequent":0}`.
После этого счётчик на сайте начнёт заполняться (первым посетителем будешь ты).

## Как это считается

- «Визит» засчитывается не чаще одного раза в день на браузер (сайт сам следит
  за этим), поэтому «часто заходят» = зашли в **3 и более разных дня**.
- Если человек очистит данные браузера, он посчитается как новый — это обычное
  ограничение любых анонимных счётчиков.
- Числа примерные (KV не гарантирует идеальный атомарный счёт при одновременных
  заходах), но для «сколько народу пользуется» этого более чем достаточно.

## Лимиты (бесплатный тариф)

Запись в KV идёт только на первые 3 визита каждого посетителя, дальше — ноль
записей. Так что бесплатных лимитов Cloudflare (100k чтений и 1k записей в день)
с огромным запасом хватает.
